# My Website

A simple personal portfolio website built using HTML and CSS. The website introduces me, presents my skills and projects, and provides links to my social and professional profiles.

## Overview

This project is a static personal website designed to showcase my background, technical skills, interests, and software projects.

The website uses multiple HTML pages connected through a shared navigation bar and a common CSS stylesheet.

## Pages

### Home

Introduces me and provides links to my professional and social profiles.

### About Me

Contains information about my background, interests, goals, and personal interests.

### Skills

Displays my technical skills and links to some of my GitHub projects.

### Contact

Provides the contact section of the website.

## Features

- Multi-page personal portfolio website
- Simple navigation between pages
- Responsive viewport configuration
- Shared CSS styling
- Personal introduction and biography
- Skills and project showcase
- Links to GitHub, LinkedIn, email, and other platforms
- Simple and lightweight static website

## Tech Stack

- HTML5
- CSS3
